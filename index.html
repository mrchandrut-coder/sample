About This Page

HTML specifies the structure of a web page. The index.html file acts as the primary entry point that web servers automatically look for when someone visits your root URL.

Useful Elements

  • Headings: Used to structure content from <h1> down to <h6>.
  • Paragraphs: Enclosed in <p> tags to break up text blocks.
  • Links: Created using the <a> tag with an href attribute.

To learn more about standard web development tags, visit the [MDN Web Docs Basics Guide](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax).
